# Project deployment

- The canonical repository is `https://github.com/kaylaorozco/professional-portfolio`.
- Production hosting is Vercel, connected to the GitHub repository.
- Keep portfolio changes local and uncommitted until Kayla has reviewed the local preview and explicitly approved committing/publishing. Approval to implement is not approval to commit or deploy.
- After local review and explicit approval, commit and push the approved changes to GitHub so Vercel can deploy them.
- Do not publish or deploy this project with OpenAI Sites.
